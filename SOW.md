# Student Project – Scope of Work (SOW)
Project Title: Linear Algebra Calculator
Student Name: Yu Jie (Jesse) Lee
Date: 10/9/25

## 1. Project Overview
As I am currently taking a linear algebra math class, I would like to create a program that can algorithmically verify operations commonly performed on matrices, such as matrix multiplication. I would also like for it to be able to do various other useful applications, like finding the solutions for the variables, determinants, inverses, and geometrical values. This would be interacted with through a text menu that allows for selecting different options and saving matrix data during a session.

## 2. Goals
- Create a navigable text menu operated through the keyboard.
- Use structs or classes to represent a matrix of numbers as well as its characteristics (e.g. det(A), det(A_n), adj(A), etc.)
- Save them where they can be freely viewed, accessed, and edited.
- Allow for elementary row operations and matrix operations (addition, multiplication).
- Be able to find transposes (method) and save them as new matrices.
- Create recursive functions to determine determinants and adjoints of matrices (methods).
- Use said functions to find the inverse of matrices and solutions to systems (methods).
- Also feature the ability to find areas and volumes using determinants.
- If at any point an operation is impossible to perform, throw human-readable errors.
